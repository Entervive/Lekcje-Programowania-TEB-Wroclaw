# JS/PHP Zadanie Podsumowujące

## Opis projektu

Projekt zawiera zadanie podsumowujące wiedzę z JavaScript i PHP. Pozwala na utrwalenie umiejętności obsługi formularzy, zapisu i odczytu danych z plików tekstowych oraz podstawowej logiki aplikacji webowych.

## Wymagania

- **XAMPP** lub inny serwer lokalny obsługujący PHP.
- Przeglądarka internetowa.
- Pliki projektu umieszczone w katalogu `htdocs` serwera XAMPP.

## Struktura projektu

- `magazyn.php` – Główny plik PHP obsługujący logikę aplikacji magazynowej.
- `historia_wyszukiwania.txt` – Plik tekstowy przechowujący historię wyszukiwań użytkownika.
- `JS_PHP_zadanie_podsumowujące.txt` – Plik pomocniczy z treścią zadania.

## Instrukcja uruchomienia

1. Skopiuj wszystkie pliki projektu do katalogu `htdocs` w folderze instalacyjnym XAMPP.
2. Uruchom serwer Apache w panelu sterowania XAMPP.
3. Otwórz przeglądarkę i przejdź do adresu `http://localhost/JS_PHP_zadanie_podsumowujące/magazyn.php`.

## Opis funkcjonalności

- Obsługa formularzy w PHP i JavaScript.
- Zapis i odczyt danych z plików tekstowych.
- Wyświetlanie historii wyszukiwań.
- Przykładowe zadania podsumowujące materiał z lekcji.

## Uwagi

- Upewnij się, że pliki tekstowe mają odpowiednie uprawnienia do zapisu na serwerze.
- W razie problemów z działaniem aplikacji sprawdź konfigurację serwera oraz komunikaty błędów PHP.
